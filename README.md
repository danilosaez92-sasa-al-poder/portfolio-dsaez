# Daniel Sáez · Portfolio

Web estática (HTML + CSS + JS, sin build). Todo el contenido está en `index.html`:
textos en español dentro de `PROJECTS` y `JOBS`, y en inglés en `PROJECTS_EN`, `JOBS_EN` y las llamadas `L("es","en")`.

Despliegue en Vercel: importar el repositorio, framework "Other", sin comando de build y con el directorio raíz del repo como salida.
